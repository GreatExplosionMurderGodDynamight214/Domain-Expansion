### 31 aug - Kickoff

Een fork van de model repository gemaakt en gepubliceerd via mijn eigen Github omgeving.
Checkout:
1. Leg uit wat een source hosting platform is en voor welke jij gekozen hebt.
   Een source hosting platform is een platform waarmee je een website op het web kunt zetten. Ik heb gekozen voor github.
2. Vertel welke domeinnaam jij gekozen hebt en hoe je die hebt gekoppeld aan jouw pagina.
   Ik heb mijn domein hollow-purple genoemd. Ik heb die gekoppeld aan mijn pagina door in TransIP een domein te kopen en daarin mijn repository van github te benoemen.
3. Beschrijf hoe je aanpassingen aan jouw pagina kunt maken en hoe je er voor zorgt dat die op het web gepubliceerd worden.
   Ik verander de code van mijn website via VSCodium. De veranderingen sla ik op en dan open ik de website opnieuw en is het aangepast.
